# GPS Tracker to HA

Custom-интеграция для `Home Assistant`, которая подключается к REST-серверу GPS-трекеров и создаёт `device_tracker` и датчики (скорость, заряд, спутники, курс) на каждое устройство.

Является современной заменой старого Java-контейнера `gps-tracker-to-ha-sender`: работает внутри самого Home Assistant, не требует API-ключа и REST-API Home Assistant, и умеет обслуживать несколько трекеров одновременно в одном процессе.

## Требования

- Запущенный сервер GPS-трекеров ([gps-tracker-server](https://github.com/6PATyCb/gps-tracker)) с REST-портом (по умолчанию `9080`), например:
  ```
  java -jar gps-tracker-server.jar --rest-port 9080
  ```
- Home Assistant (Core 2024.1+) с доступом к серверу по сети.

## Что создаётся в HA

На каждое настроенное устройство с IMEI:

- **device_tracker.**{имя} — отображается на карте (`source_type: gps`), атрибуты: координаты, скорость, курс, заряд, спутники, время.
- **sensor.**{имя}_battery — заряд аккумулятора, %.
- **sensor.**{имя}_speed — скорость, км/ч.
- **sensor.**{имя}_satellites — количество спутников.
- **sensor.**{имя}_course — курс, градусы.

Сущности можно привязать к сущности **Person** для работы с зонами.

## Установка

### Через HACS (рекомендуется)

1. Удостоверьтесь, что [HACS](https://hacs.xyz/) установлен.
2. HACS → «Пользовательские репозитории» (три точки) → добавьте `https://github.com/6PATyCb/gps-tracker-to-ha` с типом «Интеграция».
3. Скачайте интеграцию «GPS Tracker to HA» и перезапустите Home Assistant.

### Ручная установка

1. Скопируйте каталог `custom_components/gps_tracker_to_ha` в каталог `custom_components` вашего Home Assistant.
2. Перезапустите Home Assistant.

## Настройка

1. `Настройки` → `Устройства и службы` → `Добавить интеграцию` → найдите **GPS Tracker to HA**.
2. Укажите:
   - **Хост сервера** — например `127.0.0.1` или `127.0.0.1`.
   - **Порт** — например `9080`.
   - **Интервал опроса** (секунды) — по умолчанию 10.
   - **Доверять самоподписанному HTTPS-сертификату** — включать, если сервер использует свой `cert.pem`/`key.pem` (обычно так и есть), иначе подключение завершится ошибкой.
3. Добавьте одно или несколько устройств: **IMEI** и понятное имя (например `my_car`).
4. Если сервер недоступен, мастер покажет ошибку соединения.

### Изменение настроек

`Устройства и службы` → карточка интеграции → репозиторий-иконка «Настройки» (или «Параметры»). Можно изменить хост/порт/интервал, а также добавить или удалить устройства.

## Примечания

- Данные опрашиваются по схеме `GET https://{host}:{port}/gps/{imei}`. HTTP 404 означает, что трекер сейчас не подключён к серверу — сущности станут недоступными и восстановятся автоматически при появлении устройства.
- Если устройство пропало из конфигурации интеграции, его сущности будут удалены после перезагрузки записи; сам трекер (устройство) остаётся в реестре устройств HA и его при желании можно удалить вручную.
- API-ключ Home Assistant для интеграции не нужен — данные пишутся напрямую в ядро.
- Время в атрибутах приходит от трекера в его локальном времени (`yyyy-MM-dd HH:mm:ss`) и не конвертируется в часовой пояс HA.
